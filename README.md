# Research Dashboard

**A clean, single-page dashboard for research business development.** It brings researcher profiles, project status, and open industry RFPs together in one view, so a team can quickly see who is working on what and which funding fits.

### [▶ Live demo](https://jakeisaperson2.github.io/research-dashboard/)

## Features

- **Researcher Profiles**: name, department, and research focus
- **Project Tracker**: project overviews with color-coded status badges (Idea, Prototype, Seeking Funding, Clinical Validation, Completed)
- **Industry RFPs**: open opportunities with sponsor, deadline, budget, and focus area
- Reusable `DataTable` and `StatusBadge` components, with a responsive layout

## Run Locally

No install or build step is needed. Open `index.html` in any modern browser.

## Tech

React 18 and Tailwind CSS loaded from CDNs, with JSX compiled in the browser by Babel Standalone. Everything lives in one file.

> The data shown is sample data for demonstration.
